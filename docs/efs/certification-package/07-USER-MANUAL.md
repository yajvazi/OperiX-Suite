# User manual (software draft)

Normal users create invoices/POS sales as usual. The fiscal section shows `Not configured`, `Në pritje`, `Dështoi`, or a provider-confirmed final state. Users cannot enter private keys or claim an ordinary invoice is a TAK fiscal coupon.

Administrators use Settings → Business → Fiscalization to review installation readiness. Fiscalize, retry, return, correction, print, and share actions are state-dependent and remain unavailable when the hard backend guard blocks them.
