# Installation procedure

1. Confirm the exact certified release manifest.
2. Create/select the company, business unit/fiscal location, and POS terminal.
3. Enter TAK/applicant-issued fiscal data; do not generate values locally.
4. Register certificate metadata and secure key reference.
5. Run readiness diagnostics and certification fixtures in isolated certification mode.
6. Run TAK-prescribed test fiscal coupons and retain evidence.
7. Activate only after formal approval, valid configuration, and a release-specific decision.

Installation, replacement, transfer, deactivation, and maintenance records must preserve historical fiscal evidence.
