# Agent user guide

## Work a ticket

Open Tickets and use global search for a ticket number, subject, contact, email, tag, or category. Select a ticket to read the conversation and structured timeline. Change status or priority in Properties, then save an assignment when routing work to another Support agent.

## Reply versus internal note

Use Public reply for customer-visible communication. Use Internal note for staff-only context. Visibility is enforced by permissions and stored explicitly; never put sensitive content in a public reply.

## Attachments

Use Attach on the composer. Supported types include PDF, images, ZIP, TXT, and common Office files. The private storage link is short-lived. A new attachment remains pending scanner verification until the configured scanner hook marks it clean.

## Saved replies

Create and search saved replies under Saved replies. Insert the text into the composer, review ticket-specific details, and then send.

## Status meaning

Open means work is needed; Waiting on Customer means the next action belongs to the customer; Waiting on Agent means another internal action is pending; In Progress is actively being worked; Resolved is believed complete; Closed is finalized; Archived is retained but out of active queues.
